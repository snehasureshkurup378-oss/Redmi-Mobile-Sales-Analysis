Redmi Mobile Sales Data Analysis

Project Overview
This project focuses on analyzing Redmi mobile sales data to identify sales trends and understand business performance.

Project Objectives
-Analyze total revenue and profit.
-Compare sales across mobile models and states.
-Evaluate performance across different sales channels.
-Analyze monthly revenue and profit trends.
-Explore sales by storage variant.

Project Workflow
-Data cleaning and preprocessing.
-Sales data analysis.
-KPI evaluation.
-Interactive dashboard development.
-Data visualization and insights.

Tools Used
-Microsoft Excel
-Power Query
-PivotTables and PivotCharts
-Slicers

Key Performance Indicators
-Total Revenue
-Total Profit
-Total Quantity
-Total Orders
